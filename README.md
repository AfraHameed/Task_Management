# MERN Task Management Web Application

A full-stack User-Based Task Management Web Application developed using the MERN stack (MongoDB, Express.js, React.js, and Node.js).

This application allows users to register, securely login, and manage their own personal tasks. It includes JWT-based authentication, password hashing using bcrypt, protected routes, and user-specific task management.

Users can create, view, update, and delete tasks. The application also supports updating task status between pending and completed, filtering tasks by All, Completed, and Pending, along with search and sorting functionality for better task management.

Each task contains important details such as title, description, status (pending/completed), priority level (low, medium, high), and due date. Toast notifications are included to provide users with feedback during different actions, improving the overall user experience..
